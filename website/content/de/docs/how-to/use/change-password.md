Sie wollen Ihr eigenes Passwort ändern. Selbstbedienung.

## Schritte

1. Öffnen Sie das Benutzermenü oben rechts auf einer beliebigen Seite → **Einstellungen**.
2. In der **Passwort**-Karte geben Sie Ihr **aktuelles Passwort** und das **neue Passwort** zweimal ein.
3. Klicken Sie auf **Passwort ändern**.

Jeder andere Browser, der bei Ihrem Konto angemeldet ist, wird automatisch abgemeldet. Ihre aktuelle Sitzung bleibt angemeldet.

## Hinweise

- Das neue Passwort muss die Mindestlänge der Anwendung erfüllen. Wählen Sie ein langes, einzigartiges Passwort aus einem Manager — es gibt keine Wiederherstellung, wenn Sie auch Authenticator und Wiederherstellungscodes verlieren.
- Wenn ein Admin Ihr Passwort zurückgesetzt hat (weil Sie sich ausgesperrt haben), werden Sie aus dem gleichen Grund bei der nächsten Anmeldung aufgefordert, es zu ändern.
- Für *eines anderen* Nutzers Passwort (nur Admin) siehe [Passwort einer Nutzer:in zurücksetzen](../../administer/reset-user-password/).
