Sie wollen eine der Statistik-Seiten drucken (oder als PDF speichern), zum Beispiel für eine Vorstandssitzung oder ein Audit.

## Schritte

1. Navigieren Sie zum Bericht — Statistiken → Personalstunden, Kinderstatistiken, Belegungsmatrix, Finanzübersicht etc.
2. Setzen Sie etwaige Filter (Zeitraum, Bereich).
3. Klicken Sie oben auf **Drucken**.
4. Der Druckdialog Ihres Browsers öffnet sich. Wählen Sie einen Drucker oder **Als PDF speichern**.

## Hinweise

- Berichte sind druckoptimiert — die Seitenleiste, der Dark-Mode-Rahmen und interaktive Bedienelemente werden ausgeblendet, und die Diagrammfarben sind für Papier abgestimmt.
- Für eine *wiederkehrende* PDF-Verteilung (z. B. monatliches Vorstandspaket per Mail) enthält das Projekt ein separates Sidecar-Tool — siehe [Architektur](../../../explanation/architecture/) (Abschnitt Report-Tool) und das Operator-How-To zum Einrichten.
- Filter *vor* dem Drucken setzen. Die Druckansicht zeigt das, was aktuell sichtbar ist.
