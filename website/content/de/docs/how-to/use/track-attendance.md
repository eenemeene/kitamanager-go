Sie wollen festhalten, welche Kinder heute da waren (oder eine frühere Erfassung korrigieren).

## Schritte

1. Klicken Sie in der Seitenleiste auf **Anwesenheit**.
2. Die Seite öffnet sich auf der aktuellen Woche. Mit den Pfeilen über dem Raster wechseln Sie die Woche.
3. Klicken Sie für jedes Kind auf jede Tageszelle, um zwischen **anwesend** → **abwesend** → leer umzuschalten.
4. Änderungen speichern automatisch. Es gibt keine Speichern-Schaltfläche.

Die Übersicht oben zeigt die täglichen Anwesenheitssummen für die aktuelle Woche.

## Hinweise

- Anwesenheit ist tagesgenau und pro Kind. Es gibt kein Konzept von Halbtagsanwesenheit.
- Ein Kind erscheint nur dann im Raster, wenn sein Betreuungsvertrag in dieser Woche aktiv ist.
- Die vollständige Anwesenheitshistorie eines Kindes finden Sie auf dessen Detailseite (Kinder → Name anklicken) im Abschnitt Anwesenheit.
- Für das Datenmodell und Sonderfälle (Urlaub, Krankheit, Berichte) siehe [Wie Anwesenheit modelliert wird](../../../explanation/how-attendance-is-modeled/).
