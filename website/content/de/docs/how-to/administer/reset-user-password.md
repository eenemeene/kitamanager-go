---
title: Passwort einer Nutzer:in zurücksetzen
weight: 4
---

Eine Nutzer:in hat ihr Passwort verloren und kann sich nicht anmelden. Als Admin können Sie ihr ein neues ausstellen.

## Schritte

1. Öffnen Sie **Einstellungen** → **Nutzer** → klicken Sie die Nutzer:in an.
2. Klicken Sie auf **Passwort zurücksetzen**.
3. Geben Sie ein neues Initialpasswort ein (das die Person beim nächsten Login ändert).
4. Klicken Sie auf **Speichern**.

Die Nutzer:in wird auf jedem Gerät abgemeldet. Kommunizieren Sie das temporäre Passwort über einen sicheren Kanal.

## Hinweise

- Das Zurücksetzen des Passworts deaktiviert **nicht** die 2FA. Wenn die Nutzer:in sowohl Authenticator als auch Wiederherstellungscodes verloren hat, hilft nur das Passwort-Reset allein nicht. Heute ist der Wiederherstellungspfad das Löschen und Neuanlegen des Kontos; Admin-Reset von MFA-Faktoren ist auf der Roadmap.
- Das Zurücksetzen wird im Audit-Log dokumentiert.
- Für den *Self-Service-Pfad* (eigenes Passwort ändern) siehe [Passwort ändern](../../use/change-password/).
