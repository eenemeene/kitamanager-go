Sie wollen einen neuen Kollegen-Account anlegen, damit er sich anmelden kann.

## Schritte

1. Öffnen Sie in der Seitenleiste **Einstellungen** → **Nutzer**.
2. Klicken Sie auf **Erstellen**.
3. Füllen Sie **Name**, **E-Mail** (muss eindeutig sein), ein initiales **Passwort** (das die Person beim ersten Login ändert) aus, und lassen Sie **Aktiv** angekreuzt.
4. Klicken Sie auf **Speichern**.

Die Person kann sich nun mit der E-Mail und dem initialen Passwort anmelden. Schicken Sie ihr das [Tutorial für den ersten Tag](../../../tutorials/first-day-in-kitamanager/) zur Einarbeitung.

## Der Person eine Rolle in Ihrer Organisation zuweisen

Ein neuer Nutzer hat standardmäßig keine Organisationsmitgliedschaften — er kann sich anmelden, sieht aber keine Daten. Geben Sie ihm eine Rolle:

1. Öffnen Sie die Detailseite des Nutzers.
2. Klicken Sie auf **Organisation hinzufügen**.
3. Wählen Sie die Organisation und eine Rolle (`admin`, `manager`, `member`, `staff`).
4. Klicken Sie auf **Speichern**.

Für die Rollendefinitionen siehe [Referenz: RBAC](../../../reference/rbac/). Für spätere Rollenänderungen siehe [Rolle in einer Organisation zuweisen](../assign-role-in-organization/).

## Hinweise

- Ermutigen Sie neue Nutzer:innen, sofort 2FA zu aktivieren. Das Rezept [Zwei-Faktor-Authentifizierung aktivieren](../../use/enable-2fa/) führt sie durch.
- Initiale Passwörter sollten über einen sicheren Kanal kommuniziert werden — nicht über die gleiche E-Mail-Adresse, mit der das Konto erstellt wurde.
- Eine Person kann Mitglied mehrerer Organisationen mit jeweils unterschiedlicher Rolle sein.
