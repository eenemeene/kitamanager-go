You want to add a new colleague's account so they can sign in.

## Steps

1. Open **Settings** → **Users** in the sidebar.
2. Click **Create**.
3. Fill in **Name**, **Email** (must be unique), an initial **Password** (the user changes it on first sign-in), and leave **Active** ticked.
4. Click **Save**.

The user can now sign in with the email + initial password. Send them the [first-day tutorial](../../../tutorials/first-day-in-kitamanager/) to onboard.

## Assign them to your organisation

A new user has no organisation memberships by default — they can sign in but won't see any data. Give them a role:

1. Open the user's detail page.
2. Click **Add organization**.
3. Pick the organisation, pick a role (`admin`, `manager`, `member`, `staff`).
4. Click **Save**.

For the role definitions, see [Reference: RBAC](../../../reference/rbac/). For changing role assignments later, see [Assign a role in an organization](../assign-role-in-organization/).

## Notes

- Encourage new users to enable 2FA immediately. The [Enable 2FA](../../use/enable-2fa/) recipe walks them through it.
- Initial passwords should be communicated through a secure channel — not the same email you used to create the account.
- A user can be a member of multiple organisations with a different role in each.
