---

You want to record which children were present today (or correct an earlier day's record).

## Steps

1. Click **Attendance** in the sidebar.
2. The page opens to the current week. Use the arrows above the grid to switch weeks.
3. For each child, click each day cell to cycle through **present** → **absent** → cleared.
4. Changes save automatically. There is no Save button.

The summary at the top of the page shows the daily presence totals for the current week.

## Notes

- Attendance is per-day, per-child. There's no concept of half-day attendance.
- A child appears in the grid only while their care contract is active for that week.
- To see one child's full attendance history, open their detail page (Children → click name) and scroll to the Attendance section.
- For the data model and edge cases (vacation, sick days, reporting), see [How attendance is modeled](../../../explanation/how-attendance-is-modeled/).
