How-to guides are **task-oriented recipes**. Each one assumes you already know roughly what you want to achieve and shows you the steps. They're scannable; they're not lessons.

If you want to learn the system from scratch, follow a [tutorial](../tutorials/) first. If you want to look up an exact field or endpoint, go to the [reference](../reference/). If you want to understand *why* something works the way it does, see [explanation](../explanation/).

The recipes are grouped by audience:
