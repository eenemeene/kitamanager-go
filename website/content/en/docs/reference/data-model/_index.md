The KitaManager data model lives in PostgreSQL. The full ER diagram and a per-table reference are auto-generated by [`tbls`](https://github.com/k1LoW/tbls) and live in the repo at [`docs/schema/`](https://github.com/eenemeene/kitamanager-go/tree/main/docs/schema). They are regenerated whenever the schema changes; the source of truth is the running database, not these markdown files.
